# Pizza Sales Dashboard 

This project is built using **Excel** for data cleaning and preparation, and **Power BI** for interactive visualization.

##  Key Insights
- Total Revenue: 817.86K
- Orders: 21.35K
- Best-selling Category: Classic (30%)
- Peak Sales Day: Saturday
- Large size pizzas were the most popular

##  Tools & Skills Used
- **Excel**: Data cleaning, formatting, preparation
- **Power BI**: KPIs, charts, dashboards, storytelling with data

##  Learning Outcome
- Improved skills in **data analysis & visualization**
- Learned how to combine Excel preprocessing with Power BI dashboards
- Gained experience in presenting business insights effectively
